# Icon provenance

Every UI icon is drawn as original vector geometry in `src/ui_icons.rs`. Each icon is drawn from a
written spec note only. Nothing is traced, sampled, copied or derived from any Maya asset, and no
Maya image or doc text is committed. Autodesk documentation is consulted only to confirm role,
order, placement and broad colour conventions. This is a process rule; it does not claim the author
never saw Maya icons.

Authorship: AztecCraft contributors, AI-assisted (Claude). The copyright position of AI-assisted
work is unresolved. Original icons use the project license, MIT OR Apache-2.0, selected on 2026-10-16. The root
LICENSE-MIT, LICENSE-APACHE and NOTICE files land in a separate license change.
